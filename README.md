# Alexander Ng

Personal site, blogs, projects, and resume.

**Live site: [naycal.github.io](https://naycal.github.io)**

Built with [Jekyll](https://jekyllrb.com) and hosted on GitHub Pages.

## Run locally

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>. GitHub Pages builds the live site with its own Jekyll (currently 3.10) and the `jekyll-feed` plugin; the Gemfile pins Jekyll 4 for local preview only.
